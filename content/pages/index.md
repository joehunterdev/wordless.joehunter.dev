# Welcome to Wordless

A **pure PHP** flat-file CMS with zero dependencies.

## Features

- Markdown content with front matter
- File-based routing
- Native PHP templates
- File-based caching
- Plugin & event system
- Clean OOP, PSR standards throughout

## Getting Started

Drop a `.md` file in `/content/pages/` and it's live.

> No database. No composer. No magic.
